# DevSecOps Daily Security Digest - 2026-10-24

## Executive Summary
Critical unauthenticated remote code execution flaws in PHP (PHP2Shell) and GitLab are currently undergoing active exploitation in the wild. Additional high-severity RCE vulnerabilities affect Node.js Brotli stream processing, Python's Pillow library, and Linux kernel KSMBD modules. Operations teams must immediately deploy upstream updates for core runtimes and verify container signatures across AI proxy deployments.

## Critical Runtime & Framework Advisories
- **PHP Runtime: PHP2Shell RCE Vulnerabilities & Unpatched Configuration Risks** - Critical flaws (CVE-2026-109618, CVE-2026-109619) allowing unauthenticated remote code execution are facing active botnet exploitation, alongside an additional low-risk configuration flaw (CVE-2026-115560). **Action**: Upgrade immediately to PHP 8.2.35, 8.3.36, 8.4.27, or 8.5.12 as no complete mitigations exist. - **GitLab & Ruby: Critical CVSS 10.0 Unauthenticated RCE Flaw** - A vulnerability affecting all self-managed GitLab releases since 7.0 permits unauthenticated remote code execution due to underlying memory corruption in Ruby's Onigmo regex engine. **Action**: Apply emergency GitLab security updates and upgrade underlying Ruby runtimes to versions 4.0.9, 3.4.12, or 3.3.13. [GitLab Advisory](https://thehackernews.com/2026/10/critical-gitlab-flaw-cvss-100-could.html) | [Ruby Advisory](https://thehackernews.com/2026/10/ruby-fixes-three-regex-engine-bugs.html)

- **Node.js: Node2Shell Brotli Decoder RCE** - A memory corruption flaw in Node.js bundled Brotli decompression implementation allows remote code execution when parsing malformed data across 22.x, 24.x, and 26.x releases. **Action**: Upgrade Node.js runtimes to the latest security release patches for supported release lines. [Security Release Notice](https://thehackernews.com/2026/10/nodejs-brotli-decoder-bug-could-allow.html) | [Node2Shell PoC Analysis](https://thehackernews.com/2026/10/researchers-demonstrate-node2shell-rce.html)

- **Python Pillow: CVE-2026-112900 Command Injection via EPS Images** - Pillow passes EPS image filenames to Ghostscript without adequate sanitization, allowing attackers to execute arbitrary system commands via crafted image files. **Action**: Update Pillow dependencies to patched versions and restrict untrusted EPS file processing. [Advisory Link](https://thehackernews.com/2026/10/critical-flaw-in-pythons-popular-pillow.html)

## OS & Kernel Security Risks
- **Linux Kernel: KSMBD Unauthenticated Remote Code Execution Flaws** - Two unpatched CVSS 9.0 vulnerabilities (ZDI-CAN-33774, ZDI-CAN-33549) in the kernel-space SMB server `ksmbd` allow remote code execution prior to authentication or over SMB Direct. **Action**: Disable the kernel `ksmbd` module or restrict SMB access at network boundaries until mainline kernel patches are available. [Advisory Link](https://thehackernews.com/2026/10/two-cvss-90-linux-ksmbd-rce-flaws.html)
