# DevSecOps Daily Security Digest - 2026-10-24

## Executive Summary
Active exploitation targeting PHP2Shell vulnerabilities requires immediate upgrading across all PHP production environments to prevent automated botnet compromises. Critical remote code execution vulnerabilities in Python Pillow, Ruby regex processing, and Node.js Brotli decompression also demand urgent patching of application runtimes. Additionally, potential secret exposure following a Railway platform breach necessitates immediate rotation of all stored environment credentials.

## Critical Runtime & Framework Advisories
- **PHP Runtime: Active Exploitation and Emergency Patches (CVE-2026-109618, CVE-2026-109619, CVE-2026-115560)** - Threat actors are actively exploiting PHP2Shell flaws to deploy Mirai botnet variants, while PHP issued notice of a separate low-risk configuration flaw. **Action**: Immediately upgrade runtime installations to PHP [8.3.36](https://github.com/php/php-src/releases/tag/php-8.3.36), [8.4.27](https://github.com/php/php-src/releases/tag/php-8.4.27), or [8.5.12](https://github.com/php/php-src/releases/tag/php-8.5.12). [Exploit Report](https://thehackernews.com/2026/10/php2shell-exploit-attempts-hit-millions.html) | [Unpatched Advisory](https://thehackernews.com/2026/10/urgent-php-warns-of-another-unpatched.html)
- **Ruby Runtime: Onigmo Regex Engine Memory Corruption** - Three memory corruption flaws in Ruby's Onigmo regex engine allow remote code execution, triggering critical vulnerabilities in downstream applications such as GitLab. **Action**: Upgrade Ruby runtimes to versions 4.0.9, 3.4.12, or 3.3.13. [Advisory Link](https://thehackernews.com/2026/10/ruby-fixes-three-regex-engine-bugs.html)
- **Node.js: Brotli Decoder Remote Code Execution (CVE-2026-111497)** - A flaw in the bundled Brotli decoder allows attackers to execute arbitrary code on official Node.js Linux arm64 container images via crafted input streams. **Action**: Audit applications handling compressed inputs and update Node.js base images. [Advisory Link](https://thehackernews.com/2026/10/researchers-demonstrate-node2shell-rce.html)
- **Python Pillow: Ghostscript OS Command Execution (CVE-2026-112900)** - Unsanitized filename handling when opening EPS image files allows arbitrary command execution via Ghostscript calls. **Action**: Upgrade Pillow dependencies to patched versions and sanitize input file paths before passing them to image handlers. [Advisory Link](https://thehackernews.com/2026/10/critical-flaw-in-pythons-popular-pillow.html)

## Infrastructure & CI/CD Threats
- **Linux Kernel: KSMBD Unauthenticated Remote Code Execution** - Two CVSS 9.0 zero-day flaws in the in-kernel SMB server permit unauthenticated remote code execution prior to login or over SMB Direct RDMA transports. **Action**: Disable KSMBD kernel modules or restrict network access to SMB ports until mainline kernel patches are released. [Advisory Link](https://thehackernews.com/2026/10/two-cvss-90-linux-ksmbd-rce-flaws.html)
- **Railway PaaS: Customer Secrets Compromise** - Unauthorized intrusion into Railway infrastructure exposed encrypted and decrypted customer environment variables. **Action**: Immediately rotate all database credentials, API keys, and environment tokens managed on Railway. [Advisory Link](https://thehackernews.com/2026/10/railway-says-intruder-may-have-accessed.html)
- **Jenkins CI: Core Maintenance Release 2.587** - Jenkins released weekly version 2.587 containing UI error display improvements and cached label expression fixes. **Action**: Upgrade Jenkins controllers to 2.587 following standard deployment validation. [Release Link](https://github.com/jenkinsci/jenkins/releases/tag/jenkins-2.587)
