# DevSecOps Daily Security Digest - 2026-10-28

## Executive Summary
A critical arbitrary local file read vulnerability in LiteLLM requires immediate patching. Additionally, there is a surge in AI-driven automated hacking operations and social engineering targeting corporate communication channels.

## Critical Runtime & Framework Advisories
- **LiteLLM: Arbitrary Local File Read** - Authenticated users can read arbitrary local files from the proxy runtime via a crafted `vertex_ai_credentials` value sent to `/utils/transform_request`. **Action**: Review [GHSA-g5ff-637f-6q2m](https://github.com/BerriAI/litellm/security/advisories/GHSA-g5ff-637f-6q2m) and update to the latest patched version. [Source](https://github.com/BerriAI/litellm/security/advisories/GHSA-g5ff-637f-6q2m)
- **LiteLLM: Image Verification** - Recent releases (up to v1.109.0-dev.1) now utilize cosign for Docker image signatures to prevent supply chain tampering. **Action**: Implement `cosign verify` in your deployment pipeline using the provided public key. [Source](https://github.com/BerriAI/litellm/releases/tag/v1.109.0-dev.1)

## Actively Exploited & Cloud Threats
- **AI-Automated Hacking (CyberStrikeAI & ARTEX AI)** - Threat actors are using AI agents to automate hacking operations and pentesting frameworks to breach organizations at scale. **Action**: Enhance monitoring for automated reconnaissance patterns and anomalous API traffic. [Source 1](https://thehackernews.com/2026/10/cyberstrikeai-uses-44-ai-agents-to.html), [Source 2](https://www.bleepingcomputer.com/news/security/former-pentester-used-artex-ai-to-steal-82-million-data-records/)
- **Microsoft Teams Social Engineering** - Attackers are abusing the external chat feature to impersonate IT support and deploy ransomware. **Action**: Disable external chat for non-essential users or implement strict identity verification for IT support requests. [Source](https://thehackernews.com/2026/10/attackers-use-microsoft-teams-it.html)
- **Lazarus Group: Operation FlashHole** - North Korean actors are abusing South Korean security software to deploy malware using post-quantum encryption. **Action**: Audit third-party security software permissions and monitor for unauthorized encrypted outbound traffic. [Source](https://thehackernews.com/2026/10/lazarus-abuses-south-korean-security.html)
