# DevSecOps Daily Security Digest - 2026-10-28

## Executive Summary
Today's security priorities center on Microsoft's out-of-band updates revoking compromised eMudhra Certificate Authority keys and backported patches for an actively exploited Apple CoreGraphics zero-day. In supply chain security, an analytics script hijacking incident highlights the need for client-side integrity controls, while LiteLLM has updated Cosign image-signing procedures across recent builds.

## Infrastructure & PKI Updates
- **Microsoft: Out-of-Band Windows Updates Distrust eMudhra CA** - Microsoft issued out-of-band updates to remove trust from certificates associated with compromised eMudhra root keys to prevent impersonation and MitM attacks. **Action**: Deploy the OOB updates to Windows hosts that do not automatically receive root certificate trust list updates. [Advisory Link](https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-windows-oob-updates-to-distrust-emudhra-certificates/)

## Supply Chain & Web Security
- **Convertr: Third-Party Analytics Script Hijacked for Card Skimming** - Threat actors compromised a shared analytics script hosted by e-commerce platform Convertr to inject card-skimming code on customer checkout pages. **Action**: Implement Subresource Integrity (SRI) hashes for external scripts and enforce Content Security Policies (CSP) to restrict unauthorized outbound data transfers. [Advisory Link](https://www.bleepingcomputer.com/news/security/hackers-hijack-convertr-analytics-script-to-steal-payment-card-data/)

## Endpoint & Cloud Identity Threats
- **Apple: CoreGraphics Out-of-Bounds Write Flaw (CVE-2026-86950)** - Apple backported patches for an actively exploited out-of-bounds write flaw in CoreGraphics that leads to arbitrary code execution when processing crafted files. **Action**: Update older enterprise-managed iOS and iPadOS devices to the latest backported OS versions. Reports: [The Hacker News](https://thehackernews.com/2026/10/apple-backports-fix-for-exploited.html) | [BleepingComputer](https://www.bleepingcomputer.com/news/apple/apple-backports-coregraphics-zero-day-patches-to-older-iphones/)
- **Microsoft 365: AitM Phishing Attacks Exploit Session Tokens** - Adversary-in-the-Middle (AitM) campaigns are capturing and replaying valid Microsoft 365 authentication tokens to bypass MFA and breach organizational accounts. **Action**: Enforce FIDO2-based hardware security keys for MFA and configure conditional access policies to restrict session token lifespans and device context. [Advisory Link](https://thehackernews.com/2026/10/microsoft-365-token-replay-attacks.html)
