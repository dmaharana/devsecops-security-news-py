# DevSecOps Daily Security Digest - 2026-10-27

## Executive Summary
Multiple severe vulnerabilities have been disclosed in LiteLLM proxy components, allowing arbitrary local file reads, XSS, and privilege escalation to remote code execution. Concurrently, maintainers released updates changing image-signing keys, while widespread campaigns and infrastructure flaws impact PHP platforms, Tailscale, and embedded web servers.

## Critical AI Proxy & Application Advisories
- **LiteLLM: Arbitrary Local File Read via `vertex_ai_credentials`** - An authenticated proxy user can read arbitrary local files from the runtime by supplying a crafted `vertex_ai_credentials` payload to `/utils/transform_request` due to an incomplete blocklist. **Action**: Apply the latest security patch. [Advisory Link](https://github.com/BerriAI/litellm/security/advisories/GHSA-g5ff-637f-6q2m)
- **LiteLLM: Reflected XSS in `/sso/debug/callback`** - Identity provider-controlled fields are improperly escaped inside an inline script block, enabling reflected cross-site scripting via crafted input such as `</script>`. **Action**: Update to the latest patched version. [Advisory Link](https://github.com/BerriAI/litellm/security/advisories/GHSA-hhww-mrg2-969h)
- **LiteLLM: Privilege Escalation to Proxy Admin and RCE** - Reusing the proxy's salt encryption key for both secret storage and session token minting allows an authenticated user to forge admin credentials via metadata manipulation. **Action**: Upgrade immediately. [Advisory Link](https://github.com/BerriAI/litellm/security/advisories/GHSA-7hp6-4w63-5g45)
- **BerriAI/litellm: v1.103.8 Release and Cosign Key Rotation** - This release introduces a modified image-signing key (commit `e82a3c6`) for all Docker images and Helm charts, breaking verification via older commit keys. **Action**: Update verification workflows to use the new cosign key. [Release Link](https://github.com/BerriAI/litellm/releases/tag/v1.103.8)

## Runtimes, Infrastructure & Supply Chain Risks
- **PHP2Shell: Exploitation Trends** - Threat actors are actively attempting exploitation routines across PHP environments, matching systemic remediation challenges for web runtimes. **Action**: Review PHP exposure surface, restrict execution privileges, and monitor runtime access logs. [Advisory Link](https://www.wiz.io/blog/php2shell-exploitation-so-far)
- **Magento & Online Stores: Scanner-Evading JavaScript Campaign** - Nearly a thousand online stores, primarily running Magento, have been infected with sophisticated malicious JavaScript injectors active since mid-2025. **Action**: Audit e-commerce deployments for unauthorized script insertions and integrity violations. [Advisory Link](https://thehackernews.com/2026/10/hackers-infect-953-online-stores-with.html)
- **GoAhead Embedded Web Server: TLS Revocation and Session Decryption Flaws** - The GoAhead web server loads certificate revocation lists into its OpenSSL backend without enabling active checks, permitting revoked client certificates to authenticate successfully. **Action**: Apply vendor patches or reconfigure mutual-TLS backend validation constraints. [Advisory Link](https://thehackernews.com/2026/10/goahead-tls-flaws-allow-revoked-client.html)
- **Tailscale: SSH Vulnerabilities and Root Privilege Escalation** - Tailscale is addressing nearly a dozen security flaws in its SSH implementation that could permit credential theft, server disruption, and root privilege escalation. **Action**: Update Tailscale nodes to the latest patched versions. [Advisory Link](https://www.bleepingcomputer.com/news/security/tailscale-warns-of-serious-ssh-flaws-allowing-root-privilege-escalation/)
